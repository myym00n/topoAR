# ТопоAR — Android

Kotlin + ARCore + OpenGL ES 3, без сторонних библиотек.

- Сборка на GitHub: залей содержимое этой папки в репозиторий, APK появится в Releases → «latest».
- Локально: открыть папку в Android Studio → Build → Build APK(s).

Подробно — в README.md в корне проекта.

| Файл | Что делает |
|---|---|
| `MainActivity.kt` | Экран: камера, крестик, мини-карта, кнопки, загрузка пакета |
| `ArRenderer.kt` | Кадр ARCore, прицел (hit-test), отрисовка слоёв и подложки |
| `Aligner.kt` | Привязка: пары точек (МНК), визир, компас, ручная подвижка, макет |
| `MapView.kt` | Мини-карта: выбор точек, «я стою здесь», подвижка плана пальцем |
| `TopoPackage.kt` | Чтение .topoar (scene.json, *.mesh, plan.mesh, plan.png) |
| `Gl.kt` | Шейдеры, фон камеры, слои, подложка, маркеры |
| `Compass.kt` | Азимут камеры по датчику поворота |

## Версия 0.3

- **Подземка (рентген)** в 3D, макете и на участке: включаются все сети и трассы на земле, земля полупрозрачная. На участке поверх камеры земля не рисуется: видны трассы и трубы на своей глубине с выносками.
- **Чёткая подложка**: плитки из пакета (`texture_tiles`). Крупные на экране подгружаются в полном разрешении по одной в фоне (до 6–8), остальные берутся из обзорной `plan.png`. Анизотропная фильтрация и мип-уровни.
- **Модели с текстурой** (`tex_mesh` + `tex_file`) и **облака точек** (`points`, `point_size`) — круглые точки постоянного размера в метрах.
- **«Точки»**: значки точек привязки (красные — опорные, жёлтые — съёмочные, синие — колодцы).
- **«Показать всё»**: рамка по 4…96 % вершин + 8 %, направление взгляда прежнее.
- **Приближение к точке под пальцами**, двойной тап — подлететь; кнопки «Сверху» и «Сбоку». Ближняя плоскость отсечения — 0,5 % дистанции, буфер глубины 24 бит.
